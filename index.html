Cuartel de Bomberos

Ejercicio 1 · 40 pts Similar

Desarrolla un programa en Python que administre los registros de los bomberos recién incorporados al Cuartel Central de Bomberos. El programa debe validar correctamente todos los datos ingresados. Por ejemplo, si se solicitan los años de servicio del bombero, el usuario solo debe poder ingresar números enteros positivos.

Requisitos del sistema

  • Clasificar a los bomberos según su los años de servicio.
  • Contabilizar cuántos son Capitán y cuántos Voluntario.
  • Mostrar un resumen de registro al finalizar.

Cantidad de bomberos

El programa debe pedir al usuario cuántos bomberos desea registrar.

  • Debe ser un número entero positivo.
  • Si el valor es inválido, mostrar hasta recibir una entrada correcta:
    “¡Dato inválido! Ingresa un entero positivo para continuar.”

Registro por bombero

  • Identificador de Bombero: debe tener al menos 6 caracteres y no debe incluir espacios. Ejemplos válidos: BOMB001X, FIREPRO2, RESCUE7.
  • Años de Servicio: el usuario debe ingresar un número entero positivo. Si se ingresa un valor incorrecto, mostrar:
    “¡Error de registro! Ingresa un número entero positivo para los años de servicio.”

Clasificación del bombero

  • Si los años de servicio es mayor a 8, el bombero será Capitán.
  • Si los años de servicio es menor o igual a 8, será Voluntario.

Contadores automáticos

  • Número total de Capitáns.
  • Número total de Voluntarios.

Salida final

Al finalizar, mostrar un resumen con los totales registrados. Por ejemplo:
“¡El cuartel cuenta con 3 Capitanes y 6 Voluntarios! ¡Brigada lista!”

ejercicio1_1_1.py 
# ===== Ejercicio 1.1 — Cuartel de Bomberos =====

# 1) Validar la cantidad a registrar (entero positivo)
while True:
    try:
        cantidad = int(input("¿Cuántos bomberos desea registrar? "))
        if cantidad <= 0:
            print("¡Dato inválido! Ingresa un entero positivo para continuar.")
            continue
        break
    except ValueError:
        print("¡Dato inválido! Ingresa un entero positivo para continuar.")

categoria_alta = 0
categoria_baja = 0

for i in range(cantidad):
    print(f"\n--- Registro {i + 1} de {cantidad} ---")

    # 2) Validar el código (string): al menos 6 caracteres y sin espacios
    while True:
        codigo = input("Identificador de Bombero: ")
        if len(codigo) >= 6 and " " not in codigo:
            break
        print("¡Código inválido! Debe tener al menos 6 caracteres y no incluir espacios.")

    # 3) Validar el dato numérico (entero positivo)
    while True:
        try:
            valor = int(input("Años de Servicio: "))
            if valor <= 0:
                print("¡Error de registro! Ingresa un número entero positivo para los años de servicio.")
                continue
            break
        except ValueError:
            print("¡Error de registro! Ingresa un número entero positivo para los años de servicio.")

    # 4) Clasificar según el umbral
    if valor > 8:
        print("Clasificación: Capitán")
        categoria_alta += 1
    else:
        print("Clasificación: Voluntario")
        categoria_baja += 1

# 5) Resumen final
print(f"\n¡El cuartel cuenta con {categoria_alta} Capitanes y {categoria_baja} Voluntarios! ¡Brigada lista!")

Construya un programa en Python que permita gestionar los cargadores de una electrolinera mediante un menú de opciones.

El programa debe comenzar con 16 cargadores disponibles previamente cargados.

Bienvenida

“¡Bienvenido al sistema de gestión de la Electrolinera VoltGo!”

Menú principal

1. Cargadores disponibles

3. Liberar cargadores
4. Historial de cargas
5. Salir

Funcionalidades del sistema

    Permite liberar cargadores en uso. Se debe solicitar la cantidad de cargadores a liberar, validando que: sea mayor a 0 y que no supere la capacidad máxima (16 cargadores). Esta acción incrementará la cantidad de cargadores disponibles.
  4. 4. Historial de cargas
    Mostrar la cantidad de operaciones realizadas durante la sesión (contador separado). Cada ocupar aumenta el historial; cada liberar lo disminuye.
  5. 5. Salir
    Al seleccionar esta opción, el programa debe finalizar mostrando: <em class="doc-msg">&ldquo;Gracias por utilizar nuestro software, hasta la próxima.&rdquo;</em>

Si no hay capacidad suficiente para la operación solicitada, debe informarse al usuario. El programa debe repetirse hasta que el usuario elija salir y debe usar manejo de excepciones para validar la opción del menú y las cantidades ingresadas.

# ===== Ejercicio 2.7 — Cargadores de Autos Eléctricos =====

CAPACIDAD_MAXIMA = 16
disponibles = CAPACIDAD_MAXIMA
historial = 0   # contador de la sesión: sube al ocupar y baja al liberar

print("¡Bienvenido al sistema de gestión de la Electrolinera VoltGo!")

while True:
    print("\n=== MENÚ PRINCIPAL ===")
    print("1. Cargadores disponibles")
    print("2. Ocupar cargadores")
    print("3. Liberar cargadores")
    print("4. Historial de cargas")
    print("5. Salir")

    try:
        opcion = int(input("Seleccione una opción: "))
    except ValueError:
        print("¡Opción inválida! Debe ingresar un número del 1 al 5.")
        continue

    if opcion == 1:
        print(f"Cargadores disponibles: {disponibles}")

    elif opcion == 2:
        try:
            cantidad = int(input("¿Cuántos cargadores desea ocupar? "))
        except ValueError:
            print("¡Cantidad inválida! Ingresa un número entero.")
            continue
        if cantidad <= 0:
            print("La cantidad debe ser mayor a 0.")
        elif cantidad > disponibles:
            print("No hay cargadores suficientes disponibles.")
        else:
            disponibles -= cantidad
            historial += cantidad
            print(f"Operación realizada. Cargadores disponibles: {disponibles}")

    elif opcion == 3:
        try:
            cantidad = int(input("¿Cuántos cargadores desea liberar? "))
        except ValueError:
            print("¡Cantidad inválida! Ingresa un número entero.")
            continue
        if cantidad <= 0:
            print("La cantidad debe ser mayor a 0.")
        elif disponibles + cantidad > CAPACIDAD_MAXIMA:
            print(f"No puede superar la capacidad máxima ({CAPACIDAD_MAXIMA}).")
        else:
            disponibles += cantidad
            historial -= cantidad
            print(f"Operación realizada. Cargadores disponibles: {disponibles}")

    elif opcion == 4:
        print(f"Operaciones registradas en la sesión: {historial}")

    elif opcion == 5:
        print("Gracias por utilizar nuestro software, hasta la próxima.")
        break

    else:
        print("¡Opción inválida! Debe ingresar un número del 1 al 5.")

ejercicio2_2_12.py 
# ===== Ejercicio 2.12 — Hotel =====

MAX_ESTANDAR = 40
MAX_SUITE = 20
estandar = MAX_ESTANDAR
suite = MAX_SUITE
historial = 0

print("¡Bienvenido al sistema de gestión del Hotel Mirador!")

while True:
    print("\n=== MENÚ PRINCIPAL ===")
    print("1. Habitaciones disponibles")
    print("2. Realizar check-in")
    print("3. Realizar check-out")
    print("4. Historial de ocupaciones")
    print("5. Salir")
    try:
        opcion = int(input("Seleccione una opción: "))
    except ValueError:
        print("¡Opción inválida! Debe ingresar un número del 1 al 5.")
        continue

    if opcion == 1:
        print(f"Estándar: {estandar}  |  Suites: {suite}  |  Total: {estandar + suite}")
    elif opcion in (2, 3):
        tipo = input("Tipo de habitación (E = Estándar, S = Suite): ").strip().upper()
        if tipo not in ("E", "S"):
            print("Tipo inválido. Use E o S.")
            continue
        try:
            cant = int(input("¿Cuántas habitaciones? "))
        except ValueError:
            print("¡Cantidad inválida! Ingresa un número entero.")
            continue
        if cant <= 0:
            print("La cantidad debe ser mayor a 0.")
            continue
        if opcion == 2:   # check-in: reservar
            if tipo == "E" and cant <= estandar:
                estandar -= cant; historial += cant
                print(f"Check-in de {cant} Estándar. Disponibles: {estandar}")
            elif tipo == "S" and cant <= suite:
                suite -= cant; historial += cant
                print(f"Check-in de {cant} Suites. Disponibles: {suite}")
            else:
                print("No hay habitaciones suficientes de ese tipo.")
        else:             # check-out: liberar
            if tipo == "E" and estandar + cant <= MAX_ESTANDAR:
                estandar += cant; historial -= cant
                print(f"Check-out de {cant} Estándar. Disponibles: {estandar}")
            elif tipo == "S" and suite + cant <= MAX_SUITE:
                suite += cant; historial -= cant
